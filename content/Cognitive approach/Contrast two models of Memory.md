![[Working Memory Model.png]]

- Patient had no Verbal STM  but intact visual STM

## Empirical Evidence:

Dual task studies like [[Baddeley & Hitch (1974)]] and 
![[Landry and Bartling (2011)]]

- Articulatory suppression uses up phonological loop, preventing rehearsal (e.g. adding 1+2... while reading letter strings)
- Dual tasks using same slave system results in lower performance.
