**Brown and Kulik** conducted a <u>Self-Report Survey Study</u> investigating whether there is a special type of memory which is resistant to forgetting and distortion, unusually vivid, and detailed due to a *special biological mechanisms* based emotional significance, which they termed **flashbulb memories (FBM)**.

They had a set of criteria for a memory to be classified as FBM, which they established through their research:
- Personal context
- Emotional impact 
- Vividness & Detail
- Repeated exposure -> results in rehearsal 
- Long lasting
- Public element
