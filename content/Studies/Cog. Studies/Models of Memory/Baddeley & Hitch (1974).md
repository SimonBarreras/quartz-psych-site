#Study #cognitive  [[Working Memory Model]]
___

**Baddeley and Hitch** proposed the **Working Memory Model (WMM)** in 1974 as a replacement for Atkinson & Shiffrin's oversimplified STM store. The WMM reframes short-term memory as a **dynamic, multi-component system** that actively processes information.
___

**Aim:** To propose a more detailed and accurate model of short-term (working) memory that accounts for its active, multi-tasking nature, addressing limitations of the Multi-Store Model.

**The Four Components of the WMM:**

| Component | Function | Capacity |
|---|---|---|
| **Central Executive** | Attentional controller; directs resources, coordinates other components | Limited |
| **Phonological Loop** | Processes and rehearses **auditory/verbal** information | ~2 seconds of speech |
| **Visuospatial Sketchpad** | Processes **visual and spatial** information; the "inner eye" | Limited |
| **Episodic Buffer** (added 2000) | Integrates information from all components and links to LTM | Limited |

**The Phonological Loop** has two sub-components:
- **Phonological store**: Holds sound-based information briefly
- **Articulatory rehearsal process**: Inner voice that rehearses information

**Supporting Evidence:**
- **Landry & Bartling (2011)**: articulatory suppression impairs phonological loop, confirming its role in verbal WM
- **KF case study (Warrington & Shallice, 1970)**: intact LTM but damaged verbal STM; supports separate components
- **Dual-task studies**: people can perform two tasks simultaneously if they use different components (e.g., spatial + verbal) but not if they use the same one

___

## Evaluation

| Strengths | Limitations |
|---|---|
| More **realistic and detailed** than the MSM's single STM store | The **Central Executive** is poorly defined and difficult to test empirically |
| Explains **dual-task performance** (can do two tasks if different components used) | The **Episodic Buffer** (added in 2000) was added post-hoc and lacks strong direct evidence |
| Supported by **neuropsychological case studies** (KF) and experiments (Landry & Bartling) | Does not fully explain how working memory interacts with **long-term memory** |
| Useful for understanding **reading, learning, and language processing** | Focuses only on short-term/working memory and does not address LTM structure |
| The phonological loop explains **language acquisition** and word-learning | Some components (visuospatial sketchpad) are harder to test and measure |

> **Key Concept - Working Memory vs. Short-Term Memory:**
> *The WMM replaced the idea of STM as a simple 'holding area' with a complex, active workspace. Working memory is not just storage; it is the cognitive workbench where we think, reason, read, and solve problems in real-time. This makes it central to almost every higher cognitive function.*
